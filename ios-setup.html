Подключение телефона/планшета

Проверка уже прошла? Перейти к сбору всех недель ↓

Сначала проверим, может ли твой iPhone или iPad читать госдневник. Этот тест ещё не импортирует данные в School++.

Результат содержит только статусы запросов и количество недель, уроков, отметок и заданий. Личные данные и данные входа в отчёт не попадают. Скрипт обращается только к госдневнику.

  1. Создай Команду

    В приложении «Команды» нажми «+» и назови её «School++ — проверка».

  2. Включи запуск из Safari

    В свойствах Команды включи «На странице экспорта» / «Показывать в меню “Поделиться”». В типах входных данных оставь веб-страницы Safari.

  3. Добавь действие «Выполнить JavaScript на веб-странице»

    Входом должны быть входные данные Команды. Полностью замени пример кода в действии нашим скриптом.

    Показать скрипт для ручного копирования
  4. Добавь вывод результата

    После JavaScript добавь «Скопировать в буфер обмена», затем «Показать результат». Оба действия должны получать результат JavaScript.

  5. Разреши сценарии

    В настройках приложения «Команды», в разделе «Дополнительно», включи разрешение на выполнение сценариев. Название пункта может немного отличаться в разных версиях системы.

  6. Запусти из госдневника

    Открой diary.e-schools.by именно в Safari, войди и переключи одну неделю. Затем нажми «Поделиться → School++ — проверка» и разреши работу со страницей.

  7. Пришли результат проверки в наш чат

    Результат скопируется в буфер. Это короткий текст, начинающийся с schoolpp-ios-probe-v1. Если сама iOS показала ошибку до появления отчёта, пришли её текст.

Второй этап: все недели

Первая проверка подтвердила доступ на iPhone. Теперь проверим полный сбор и отображение твоего дневника. В той же Команде замени только скрипт — остальные действия оставь.

Показать скрипт полного сбора для ручного копирования

Результат второго этапа содержит твой дневник. Не присылай его в чат: вставь ниже на этой странице. Разбор происходит на телефоне. Кнопка короткого отчёта скопирует только счётчики, без ФИО, ДЗ и данных входа.

Обнови скрипт и запусти Команду из госдневника через «Поделиться». Вернись сюда и вставь скопированный результат. Если iOS прервёт выполнение — пришли текст ошибки.

Тестовый просмотр доступен локально. Он не меняет подключение по коду и данные на сервере. Вложения, требующие отдельного скачивания, будут следующим этапом.
