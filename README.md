# School++

School++ — альтернативный интерфейс электронного дневника для учеников,
использующих e.school.by.

Режим `local` используется для разработки интерфейса с пустыми школьными
данными. Настоящий вход и облачное хранение включаются настройкой
`VITE_APP_MODE=cloud`.

## Возможности

- дневник ученика с расписанием по дням, неделям и четвертям;
- календарь на весь учебный год и возврат к текущей неделе;
- расписание звонков, каникул и уроков, список предметов;
- успеваемость по предметам: текущие отметки, средние баллы, итоги четвертей и года;
- итоговая таблица четвертей, полугодий и года с поведением;
- домашние задания, материалы, отметки и посещаемость в контексте урока;
- обзор класса с классным руководителем и списком учеников;
- кабинет учителя с выбором класса, предмета и учебной группы;
- журнал четверти с отметками, `Н`, замечаниями и домашними заданиями;
- годовая таблица учителя, поиск ученика и навигация по ячейкам стрелками;
- отдельная мобильная композиция, светлая и тёмная темы;
- интерактивное знакомство с продуктом при первом запуске;
- расширение для переноса данных из `diary.e-schools.by` в School++;
- облачное сохранение снимка и встроенная поддержка с операторской страницей.

## Запуск

Установите Node.js 22.12+ или 24, затем выполните в PowerShell:

```powershell
cd D:\school++
npm.cmd ci
npm.cmd run dev
```

Откройте адрес, который выведет Vite. Для проверки проекта:

```powershell
npm.cmd test
npm.cmd run lint
npm.cmd run build
npm.cmd run extension:package
```

Собранную версию из `dist/` можно проверить командой `npm.cmd run preview`.
Иконки включены в приложение и не загружаются с внешнего CDN.

Облачный режим Supabase автоматически создаёт техническую сессию браузера и
открывает синхронизированный дневник без отдельной регистрации. Настройка описана в
[docs/supabase.md](docs/supabase.md), а расширение — в
[docs/browser-extension.md](docs/browser-extension.md).

Дневник использует настоящую дату в часовом поясе школы и календарь 2026/2027.
Границы четвертей задаются в `data/school-data.js`.
Записи предыдущего учебного года сохраняются в браузере, но не переносятся
на новые занятия. Профиль, фото и выбранная тема сохраняются.

## Локальная разработка интерфейса

| Роль          | Логин     | Пароль    |
| ------------- | --------- | --------- |
| Ученик        | `student` | `student` |
| Учитель       | `teacher` | `teacher` |
| Администратор | `admin`   | `admin`   |

Ссылка «Что такое School++?» на экране входа открывает короткую интерактивную
презентацию продукта. Между сценами можно переходить колесом мыши, стрелками,
`Page Up` / `Page Down` или свайпом на телефоне. Изменённые оценки, профиль и фото
хранятся только в текущем браузере. Локальные изменения пустых экранов хранятся
отдельно от прежних записей; тема сохраняется между режимами.

## Структура проекта

```text
index.html      HTML-каркас экранов и модальных окон
script.js       сборка приложения и переключение ролей
data/           локальные данные для разработки интерфейса
extension/      расширение синхронизации для Chromium и Firefox
js/             модели, контроллеры и отдельные возможности
styles/         стили по экранам и функциональным областям
tests/          модульные тесты на встроенном Node.js test runner
```

Основные границы:

- `auth-*` отвечает за вход в локальном режиме разработки;
- `presentation-controller.js` управляет интерактивным знакомством с продуктом;
- `student-dashboard-controller.js` управляет кабинетом ученика;
- `student-class-controller.js` собирает обзор класса и состава учеников;
- `teacher-mode.js` управляет журналом учителя;
- `diary-*` нормализует и отображает расписание;
- `user-store.js` хранит безопасную ссылку на сессию и локальные изменения профиля;
- `demo-repositories.js` собирает локальные реализации репозиториев пользователей, журнала и аватаров;
- `style.css` только подключает тематические файлы из `styles/` в нужном порядке.

Ученический дневник включает четыре четверти и полноценную навигацию по учебным неделям. Учительский журнал показывает выбранную четверть целиком: список учеников закреплён слева, даты прокручиваются, а средний балл и четвертная отметка находятся в конце журнала. В клетке можно поставить до двух отметок или `Н`, добавить замечание; из заголовка даты задаются общее домашнее задание и безопасные ссылки на материалы.

Исходный набор для тестов определён в `data/school-data.js`.
`js/local-preview-data.js` создаёт из него пустые данные для текущих экранов.
