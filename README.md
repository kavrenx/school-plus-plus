# School++

School++ — альтернативный интерфейс ученического дневника [e-schools.by](https://diary.e-schools.by).

Сайт: [schoolpp.com](https://schoolpp.com).

## Возможности

- Расписание, домашние задания, материалы, отметки и посещаемость.
- Средние баллы, официальные итоги, прогнозы и статистика по предметам.
- История изменений дневника.
- Синхронизация через расширение Chromium/Firefox или Userscripts в Safari.
- Подключение дополнительного устройства по QR-коду с подтверждением владельца.
- Светлая и тёмная темы, интерфейс для компьютеров и телефонов, встроенная поддержка.

## Разработка

Требуется Node.js 22.12+ и npm. После клонирования репозитория выполните:

```sh
npm ci
npm run dev
```

Vite выведет адрес локального приложения. По умолчанию приложение использует режим
`local` с пустыми школьными данными. Облачный режим задаётся через
`VITE_APP_MODE=cloud`; имена переменных конфигурации приведены в [.env.example](.env.example).
Серверные секреты в браузерную конфигурацию добавлять нельзя.

```sh
npm test
npm run lint
npm run format:check
npm run build
```

На Windows при необходимости используйте `npm.cmd`. Сборка сайта создаётся в `dist/`;
`npm run preview` открывает её локально. Режим cloud нужно явно задать и при сборке.
Для release-архивов расширения используйте `npm run extension:package`.

## Исходники

Приложение использует JavaScript ES modules и Vite. `script.js` собирает приложение,
`js/` содержит модели и контроллеры, `styles/` — стили, `extension/` — расширение,
`tests/` — автоматические проверки, `supabase/` — миграции и серверные функции.
