# Выпуск расширения 1.0.1

Готовые пакеты создаёт команда:

```powershell
npm.cmd run extension:package
```

Результат:

- `.extension-dist/schoolpp-chromium-1.0.1.zip` — Chrome Web Store; тот же пакет
  подходит Chromium-браузерам;
- `.extension-dist/schoolpp-firefox-1.0.1.zip` — Firefox Add-ons.

Версия Firefox 140 или новее обязательна: она поддерживает встроенное согласие
Mozilla на передачу данных, объявленное в манифесте расширения.

## Текст карточки

**Название:** School++ — синхронизация дневника

**Краткое описание:** Переносит расписание, домашние задания и отметки из
e-schools.by в понятный дневник School++.

**Назначение:** Расширение работает на странице электронного дневника
e-schools.by, собирает доступные вошедшему ученику учебные данные и передаёт их в
School++. Логин, пароль, cookies, токены авторизации и CAPTCHA не сохраняются.

## Обоснование разрешений

- `storage` — хранение снимка дневника, времени последнего обновления и настройки
  фоновой синхронизации;
- `alarms` — запуск проверки примерно раз в 15 минут после первой ручной
  синхронизации;
- `notifications` — сообщение, если закончилась сессия, мешает VPN или
  e-schools.by недоступен;
- доступ к `diary.e-schools.by` — чтение учебных данных уже вошедшего пользователя;
- доступ к `schoolpp.com` — передача снимка в личное хранилище и подтверждение
  завершённой записи.

Удалённый код не используется. Все исполняемые файлы находятся внутри пакета.

## Инструкция проверяющему

1. Войти в тестовый аккаунт на `https://diary.e-schools.by/`.
2. Открыть расширение и нажать «Синхронизировать».
3. Убедиться, что статус стал зелёным и появилась кнопка «Открыть School++».
4. Открыть School++ и проверить расписание, отметки и профиль.
5. В настройках расширения проверить переключатель фонового обновления.
6. Нажать «Удалить данные» и убедиться, что локальная и облачная копии очищены.

Если магазин запросит тестовый аккаунт e-schools.by, его нельзя публиковать в
описании. Передайте проверяющему отдельные временные данные через защищённое поле
инструкций магазина.

## После публикации

Скопируйте адреса карточек в `js/release-config.js`: Chrome Web Store в
`chromium`, Firefox Add-ons в `firefox`. Затем снова
соберите и опубликуйте сайт. До этого карточки установки на первом экране
помечены как недоступные.
