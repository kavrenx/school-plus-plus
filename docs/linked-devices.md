# Дневник на компьютере и телефоне

Компьютер с расширением получает данные e-schools.by. Подключённый браузер телефона читает сохранённый дневник и общую историю изменений. Статистика и расчёт цели работают на обоих устройствах.

## Сервер

Один раз выполнить в SQL Editor проекта Supabase файл `supabase/migrations/202610140001_linked_devices.sql`. Нужны уже установленные миграции личного дневника и включённые анонимные сеансы Auth.

В проекте School++ (`eglwyqykybpzxusnteul`) миграция применена 14 октября 2026 года. Повторно выполнять её не нужно. Проверка всех семи условий защиты и доступности функций завершилась успешно.

Код действует пять минут и используется один раз. После ввода на телефоне владелец подтверждает запрос на компьютере, сверив четырёхсимвольный код. До подтверждения данные недоступны. Подключается до пяти устройств. Токен компьютера не переносится на телефон. Запросы ограничены пятью попытками за пять минут на сеанс; таблицы закрыты для прямого доступа, сервер проверяет владельца каждого действия.

## Локальная проверка

1. Запустить `npm run dev -- --host 0.0.0.0 --port 5174 --strictPort`.
2. Пересобрать локальную папку через `npm run extension:build`, обновить распакованное расширение из `.extension-dist/chromium`. Эта папка поддерживает `http://127.0.0.1/*` и `http://localhost/*`. Публикуемые сборки создаются с `--release` и не содержат этих разрешений.
3. Открыть на компьютере `http://127.0.0.1:5174/`, синхронизировать дневник.
4. Для телефона в той же Wi-Fi сети указать адрес компьютера в `.env.local`: `VITE_PAIRING_ORIGIN=http://<адрес-компьютера>:5174`, затем перезапустить сервер. QR будет вести на этот адрес; `127.0.0.1` на телефоне указывает на сам телефон.
5. В аккаунте открыть «Мои устройства» → «Подключить устройство». Отсканировать QR телефоном или открыть локальный сайт и ввести код. Сверить код подтверждения и разрешить подключение на компьютере.
6. Проверить дневник, итоги, цель и историю изменений на телефоне. После синхронизации компьютера телефон проверяет обновления раз в пять секунд, пока вкладка видима. Выбранный день и раздел сохраняются.
7. Переименовать или отключить телефон в «Мои устройства». При отключении он возвращается к подключению; удаление дневника на компьютере также отзывает доступ.

## Поведение при потере связи

Загруженный дневник остаётся на экране. Последний снимок сохраняется отдельно для сеанса телефона; ошибки обновления обозначаются под заголовком. После восстановления связи обновления возобновляются. Это кэш данных, а не установка отдельного офлайн-приложения: первая загрузка сайта требует соединения.

Файлы e-schools.by пока скачиваются на компьютере через расширение. На телефоне показывается понятное сообщение об этом ограничении. Чаты поддержки остаются отдельными для каждого браузера. Отметки о прочтении истории также отдельны; сам список изменений общий. Неотправленные изменения сохраняются на компьютере и повторно передаются при следующей загрузке или синхронизации.

При очистке данных браузера телефон нужно подключить снова. Код в QR не содержит токен сеанса и сам по себе не открывает дневник.
