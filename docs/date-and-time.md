# Даты и время в School++

## Канонические форматы

- Календарная дата школы хранится строкой `YYYY-MM-DD`. Она не является моментом времени и не преобразуется через `toISOString()`.
- Время урока хранится отдельно в формате `HH:mm` (`startsAt`, `endsAt`).
- Момент изменения записи журнала хранится как ISO timestamp в UTC, например `2026-08-24T12:00:00.000Z`.
- Часовой пояс берётся только из `School.timezone` в формате IANA, для demo — `Europe/Minsk`.

## Что считается «сегодня»

Интерфейс получает текущий момент и переводит его в календарную дату школы. Часовой пояс компьютера пользователя не меняет выбранный день, приветствие, счётчики или отметку текущей даты.

## Учебный год, четверти и каникулы

`AcademicYear` содержит стабильный `id`, подпись и включительные границы `startsOn`/`endsOn`. Четверти хранятся отдельными диапазонами в `AcademicYear.terms`, каникулы — в `AcademicYear.breaks`. Сообщение о летних каникулах показывается только тогда, когда школьная дата входит в явно заданный диапазон с типом `summer`.

Неделя, шаблон расписания и конкретный урок получают `schoolYearId`. Это позволяет хранить одинаковые классы и расписания в нескольких учебных годах без связи по текстовой подписи вроде `2025/2026`.

Текущий демонстрационный календарь — 2026/2027; границы четвертей являются
настройками вымышленной школы. Неделя всегда начинается в понедельник, даже
если четверть начинается во вторник. Дни до начала и после конца четверти
не получают уроков. Метаданные дневника берут название года из `School`,
чтобы оно не расходилось с календарём.

Для автоматического определения обработанного занятия текущий момент переводится в дату и время школы. Урок считается завершившимся только после `date + endsAt`; одного прошедшего времени недостаточно — в уроке должна существовать хотя бы одна содержательная запись учителя.

## Правила для будущего API

- API принимает и возвращает даты уроков как `YYYY-MM-DD`, не как timestamp.
- API возвращает timestamp аудита в UTC; клиент форматирует его в часовом поясе школы.
- Сервер проверяет, что дата урока и период каникул принадлежат указанному учебному году.
- Переход через месяц, год и високосный день покрывается тестами календарной арифметики.
