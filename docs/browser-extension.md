# Расширение School++

Расширение переносит данные из `diary.e-schools.by` в личное хранилище School++. Оно не
просит логин или пароль от государственного дневника и работает с уже открытой
пользователем сессией.

## Как проходит синхронизация

1. Пользователь входит в `diary.e-schools.by` обычным способом.
2. Расширение запоминает ответы дневника и по нажатию кнопки считывает текущую
   страницу.
   При следующем открытии дневника оно также проверяет, пора ли обновить пакет.
   После первой ручной синхронизации повторная проверка проходит примерно раз в
   15 минут. Если вкладка дневника закрыта и фоновое обновление включено,
   расширение открывает её неактивной, выполняет синхронизацию и закрывает после
   успешного завершения.
3. Расширение также получает справочник кабинетов, чтобы расписание сохраняло
   кабинет конкретного урока и дня.
4. Пользователь открывает `schoolpp.com`; отдельный логин School++ не нужен.
5. Страница запрашивает подготовленный пакет у расширения и сохраняет его в
   личную техническую сессию Supabase.
6. Локальная копия остаётся для следующих автоматических обновлений. Пользователь
   может удалить её кнопкой в расширении.

Пароли, cookies, токены, ответы авторизации и CAPTCHA не записываются. Перед
сохранением расширение дополнительно скрывает поля с чувствительными названиями.

## Браузеры

Исходный код общий. Сборка создаёт два каталога:

- `.extension-dist/chromium` — Chrome, Brave, Edge, Opera и другие браузеры на
  Chromium;
- `.extension-dist/firefox` — Firefox.

Команда финальной упаковки:

```powershell
npm.cmd run extension:package
```

Готовые архивы для магазинов находятся в `.extension-dist/`. Для локальной
проверки Chromium откройте страницу управления расширениями,
включите режим разработчика и выберите «Загрузить распакованное расширение».
Укажите каталог `.extension-dist/chromium`.

В Firefox откройте `about:debugging`, выберите временную загрузку дополнения и
укажите `.extension-dist/firefox/manifest.json`.

Кнопка «Открыть School++» активирует уже открытую вкладку сайта. Если вкладки
нет, расширение открывает `https://schoolpp.com/`.
Собранные ответы хранятся локально и не теряются при включении VPN после
завершения работы с e.school.by.

Фоновое обновление включается после первой
ручной синхронизации и останавливается после удаления данных. Оно использует
сохранённую браузером сессию e.school.by, но не хранит логин, пароль или
сессионный токен. Если сессия закончилась, мешает VPN или сайт не отвечает,
расширение закрывает временную вкладку и показывает системное уведомление.
Браузер должен быть запущен; пропущенная во время сна проверка может выполниться
позже.

После фоновой синхронизации расширение передаёт снимок в уже открытую вкладку
School++ либо ненадолго открывает служебную вкладку для записи в Supabase.
Кнопка удаления очищает и локальную, и облачную копию.
