# Разделы ученика

Основная навигация: «Дневник», «Расписание», «Итоги».
Supabase включается отдельно, настройкой режима; текущие экраны работают локально.

## Даты

Календарь ограничен `academicYear.startsOn` и `academicYear.endsOn` включительно.
Пустые недели между четвертями и летом добавляются для навигации без создания
уроков. Дни за границами учебного года отключены. «Текущая неделя» появляется
на другой неделе и возвращает на сегодняшнюю дату в часовом поясе школы.

## Итоги

Порядок колонок: I, II, III, IV четверти и год.
Заголовок I полугодия находится в колонке II четверти, II полугодия — в колонке IV.
Для каждого предмета используется один тип периода: либо четыре четверти, либо
два полугодия. В одной ячейке никогда не показываются две итоговые отметки и два
средних. Режим предмета задаёт `assessmentPeriod: "quarter" | "half-year"`;
при импорте также распознаются поля `reportingPeriod` и `gradingPeriod`.
Выставленная отметка отображается основным цветом, при её отсутствии — среднее
текущих числовых отметок за период приглушённым цветом либо прочерк.
Обе отметки за урок учитываются отдельно; прогноз полугодия взвешивает все
отметки, а не средние четвертей. Пропуски и зачёты в среднее не входят.

Строка «Средний балл» учитывает только выставленные числовые итоговые отметки
предметов в соответствующей колонке. Прогнозы туда не входят.
Поведение читается из репозитория итогов с `assignmentId = "behavior"`.

Ключ четверти — её ID; ключ года — ID учебного года. Ключи полугодий берутся из
`academicYear.halfYears[].id`, либо по умолчанию `${year.id}_half_1` и `_half_2`.
Итоговые отметки полугодий и года хранятся отдельно и не назначаются клиентским
расчётом. Просмотр отдельных текущих отметок из таблицы итогов отключён.

## Данные расписания

`schoolData.schedule` передаётся нормализованной модели без подстановки
расписаний других школ. Отсутствующие данные отображаются прочерком.

- `preferredShiftId` определяет первую отображаемую смену.
- `bellSchedules[]`: `id`, `title`, `order`, `variants[]`.
  Вариант: `title`, `lessons[]` с `number`, `startsAt`, `endsAt`.
- `holidays[]`: `title`, `startsOn`, `endsOn`, необязательный `applicability`.
  Продолжительность вычисляется включительно; ограничения показываются
  рядом с названием, без звёздочек и отдельной сноски.
- `lessonSchedule[]`: `classId`, `title`, `lessons[]`.
  Урок: `time`, `subject`, `teacher`, `room`, необязательные `groups[]`
  с `title`, `teacher`, `room`.
- `subjects[]`: `classId`, `title`, `level`, `teachers[]`.
  Преподаватель: `name`, `group`, `level`.
  Без отдельного списка используются предметы учебных шаблонов своего класса
  и доступных ученику групп.

`schoolData.messages[]` содержит `date`, `classId`, `text`. В дневнике показаны
сообщения за выбранный день и класс. Счётчик пропусков считает уроки этого дня
с подтверждённым статусом `absent`.

Названия, преподаватели и сообщения экранируются перед вставкой в HTML.
Права доступа к импортируемым данным должны обеспечиваться сервером;
фильтрация по классу на экране сама по себе не является защитой.
