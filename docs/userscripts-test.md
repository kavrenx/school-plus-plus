# School++: тест Userscripts на iPhone

Архив исходной локальной проверки. Проверка на устройстве подтверждена
пользователем. Текущая обычная версия и порядок её проверки описаны в
[userscripts.md](userscripts.md); страница настройки теперь относится к ней.
Ниже сохранено описание исходного тестового протокола и его ограничений.

## Установка

Открыть `/userscripts-setup.html` на телефоне в обычном Safari, в одной Wi-Fi
сети с dev-компьютером. Установить Userscripts из App Store, запустить его,
включить расширение и разрешить работу на локальном адресе и
`diary.e-schools.by`. Кнопка установки открывает `/schoolpp-test.user.js`:
нужно открыть меню Userscripts в Safari и подтвердить установку скрипта.
Переписывать JavaScript или создавать Команду не требуется.

Тестовый инсталлятор доступен только при `vite dev`. Плагин собирает файл из
общего сборщика и транспортного модуля, поэтому нет второй копии парсера.
Список адресов включает localhost/127.0.0.1 на порту dev-сервера и приватный
`VITE_PAIRING_ORIGIN`, если он настроен. Production-домены в тест не включены.
Матчи Safari задаются для хоста, а runtime дополнительно проверяет точный origin
с портом. Изменение адреса/версии требует переустановки тестового скрипта.

## Сбор и передача

1. Страница подтверждает наличие совместимого скрипта через события общего
   документа с JSON-строкой, проверкой target/origin и случайным ID.
   Изолированные контексты Safari не обязаны возвращать одинаковый window
   в MessageEvent.source, поэтому сравнение окон не используется. Версия
   0.1.1-test заменяет предыдущий postMessage-мост. После обновления скрипта
   нужно перезагрузить страницу. Короткий отчёт различает отсутствие ответа,
   ошибку запуска и недоступность нужных GM API; отсутствие ответа не означает,
   что скрипт не установлен.
2. Скрипт сохраняет попытку в GM storage, привязывает её к текущей вкладке
   через `GM.getTab/saveTab` и переходит в госдневник в этой же вкладке.
3. При загрузке госдневника без активной попытки ничего не собирается.
   Для активной попытки ожидается загрузка запроса уроков, затем запускается
   общий сборщик. На странице показываются прогресс, повтор и возврат.
4. Токены сессии используются только внутри сборщика для GET к госдневнику.
   В GM storage попадает только очищенный образовательный снимок, без заголовков,
   значений sessionStorage/localStorage, паролей или токенов входа.
5. Результат сохраняется в GM storage и вкладка возвращается на фиксированный
   адрес настройки. Страница принимает только результат своей попытки и вкладки,
   проверяет полноту и совместимость со стандартным адаптером.
6. После сохранения в локальный тестовый кэш страница подтверждает получение.
   Результат в GM storage удаляется, открывается локальный дневник.

API GM проверены по документации release/4.x.x Userscripts. Реальное поведение
вкладок, изолированного контекста и передачи большого снимка ещё нужно
подтвердить на устройстве. Установка браузерного расширения не заменяется
обычной кнопкой сайта: её нужно включить и выдать разрешения один раз.

## Ограничения и ошибки

- Страница автоматически проверяет связь при открытии. Под заголовком всегда
  есть индикатор: ожидание, зелёный после совместимого ответа основного скрипта
  или красный при ошибке. Отсутствие запуска Userscripts не мешает сайту показать
  красный статус. Успех короткой проверки сам по себе не означает готовность
  основного скрипта. Поздний запуск перепроверяется по изменению маркеров.
- Если `connection.injected: false`, это означает отсутствие маркера основного
  скрипта, а не доказанное отсутствие установки или ошибка GM API. Возможны
  незапущенная/старая версия, ранний выход по origin/frame или отказ инъекции.
  `/schoolpp-launch-check.user.js` — отдельная минимальная проверка с другим
  именем, `document-end`, `content` и `@grant none`, только для локальных хостов.
  На странице настройки она показывает видимую плашку и записывает в отчёт
  версию, факт выполнения, совпадение origin/верхнего окна и готовность документа.
  Дневник, storage и сеть не читает. Если плашки нет после установки и полной
  перезагрузки, нужно проверять запуск/разрешения/файлы Userscripts. Если она
  появилась, а основной маркер отсутствует, исследовать основной файл, его
  версию и ранние проверки. Проверка доступна только в dev; её можно отключить
  после диагностики.
- Попытка живёт не более 3 минут; сбор — не более 45 секунд, запрос — 5 секунд.
- При истёкшем входе сбор не перезапускается на собственных неудачных запросах:
  ждёт нового запроса страницы после входа или явного «Повторить».
- При отмене контроллер останавливает запросы; поздний ответ не может заменить
  состояние отменённой или другой попытки. Уход со страницы прерывает сбор.
- Частичный снимок не заменяет предыдущие данные. Ошибки передаются понятными
  состояниями, без исходных сетевых ошибок и данных сессии.
- Чужая вкладка/другой origin не могут забрать результат. Удаляются только ключи
  с нашим префиксом; просроченные попытки очищаются при последующих запусках.
- Готовый локальный кэш используется до 7 дней. Новая синхронизация предлагается
  автоматически при открытии/возврате в видимую вкладку после 10 минут; после
  попытки действует пауза 2 минуты. Есть ручное обновление.
- В тестовом просмотре нет облачного чтения/сохранения/фонового обновления;
  обычное подключение и данные на сервере остаются прежними.
- «Завершить тест» удаляет только тестовый кэш и попытку и открывает обычный
  дневник. Данные расширения, облачный кэш и привязка устройств не удаляются.

## Перед общей версией

На реальном телефоне подтвердить установку, обнаружение, вход, все недели,
ФИО, отметки, возврат, повторное открытие и отказ сети. Отдельно проверить
доступ к вложениям. Затем подключить серверное сохранение и права владельца:
сейчас связанный телефон имеет только чтение и не должен молча перезаписывать
дневник компьютера. Понадобится явная привязка нового способа синхронизации.
После проверки подготовить общую страницу и инсталлятор для production.

Документация: [Userscripts release API](https://github.com/quoid/userscripts/tree/release/4.x.x#api),
[Userscripts в App Store](https://apps.apple.com/by/app/userscripts/id1463298887).
