# Очистка вложений поддержки

Функция удаляет из приватного Storage файлы поддержки старше трёх дней и
оставляет метаданные сообщения, чтобы в чате отображалось, что вложение больше
недоступно.

После применения миграции разверните функцию:

```text
supabase functions deploy cleanup-support-attachments --no-verify-jwt
```

В Supabase Dashboard откройте **Integrations → Cron → Jobs**, создайте задание
раз в час, выберите `cleanup-support-attachments` и через меню заголовков
добавьте встроенный секретный ключ Supabase (`apikey`).

Секретный ключ хранится только в Supabase Cron. Его нельзя добавлять в
переменные сайта, репозиторий, расширение или документацию.
